# 🎓 Student Grade Management System

A professional Student Grade Management System built using Python, Pandas and Streamlit.

This project allows users to manage student records and analyze academic performance through an interactive dashboard.

---

## 🚀 Features

- 🎓 Student Management Dashboard
- ➕ Add Student
- ✏️ Update Student
- 🗑️ Delete Student
- 🔍 Search Student
- 📋 View All Students
- 📊 Student Statistics
- 🏆 Student Ranking
- 📈 Marks Distribution
- 📊 Grade Distribution
- ✅ Pass/Fail Analysis
- 💾 CSV Data Storage
- 🎨 Professional Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- CSV
- Git & GitHub
